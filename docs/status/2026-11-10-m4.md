## Patterns and fixes to process
- Same-frame double taps recurred in three PRs. Every worker spec now requires a no-pump double-tap test on each primary action.
- Messages sent to a worker mid-task were sometimes not applied. Changes now go as their own round, and the manager checks them in the diff before merging.
- GitHub holds `pull_request` runs triggered by the bot's golden commit for approval. Workers push an empty commit so CI runs on the exact head.
- The M3 report gave the wrong due dates for M3/M4. The milestones are 6 Dec and 16 Dec.
