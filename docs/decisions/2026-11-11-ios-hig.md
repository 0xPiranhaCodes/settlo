# iOS Human Interface Guidelines: manager decisions for #158

**Date:** 11 Nov 2026 · **Decided by:** Manager

These answer the open questions in the phase 1 audit
([docs/design/158/audit.md](../design/158/audit.md)). They hold for every
implementation PR under #158. Android keeps Material behaviour throughout.

1. **Destructive colour.** System red appears only inside native Cupertino
   alerts and action sheets, where Apple's own apps use it. Coral stays the
   destructive colour everywhere else.
2. **Icons.** `cupertino_icons` is approved for system actions only: back,
   share, more, add, delete and checkmark. Settlo's custom glyphs stay for
   brand concepts and tab icons. There is no native SF Symbols view. See
   [the cupertino_icons ADR](2026-11-11-cupertino-icons.md).
3. **Sheets.** No true detents in this round. Full tasks use a full-height
   `CupertinoSheetRoute`; small confirmations stay content-sized sheets.
   Native detents are a follow-up issue.
4. **Brand.** Every tint, switch-on colour and selection colour uses a Settlo
   token, never Apple system blue. Text stays on Figtree and the #145 type
   ramp. Native alerts and action sheets render their buttons in the system
   font, as the audit's conflicts section accepts.
