# CI runs locally while GitHub Actions is out of budget

**Date:** 9 Nov 2026 · **Decided by:** Owner ("Skip CI runs") · **Raised in:** #39

## Context
GitHub Actions on the private repo stopped: "an Actions budget is preventing further use". The owner chose not to add spend and not to make the repo public.

## Decision
- Automatic Actions runs are switched off: `.github/workflows/ci.yml` runs on `workflow_dispatch` only. The workflow stays the reference definition of the gates.
- `scripts/ci-local.sh` runs the same jobs on this Mac: root analyze; tests with the coverage ratchet and the 80% money floor; Supabase (per-worktree stack, pgTAP, deno test); Android debug build; iOS no-codesign build; app and core goldens compared inside a pinned Linux Flutter container (Docker), the same rasteriser as the old CI job.
- Merge rule "CI green" now means: the **reviewer** (never the author) runs `scripts/ci-local.sh` on the PR head and pastes the summary in their APPROVE comment with the commit SHA. A PR without that summary is not merged.
- Re-enable automatic runs if the owner later adds an Actions budget.

## Consequences
Checks cost local machine time and depend on the reviewer running them; the SHA in the review ties the result to what is merged.
